# Okto Calc 1.5

- A cleaner, minimal interface with circular keys and refined typography.
- Redesigned settings and calculation history.
- Dedicated backspace: tap to delete, hold to clear the input.
- Quick sign switching and preserved scientific functions.
- Light, dark and system themes, with an optional orange accent.
- Preferences for key sounds, haptics and saving calculation history.

Android 8.0 or newer. Install OktoCalc.apk to update the app.
